# 빅뱅 유니버스

한 점(특이점)에서 시작해 138억 년 뒤까지, 시대마다 선택지를 골라 나만의 우주를 만들어 보는 게임이에요.
고른 선택에 따라 우주의 밀도, 요동, 물질, 원소 비율, 암흑물질, 암흑에너지가 바뀌고, 그 값으로 14가지 결말 중 하나가 정해져요.

이 저장소는 **Godot 4로 만드는 정식 버전**이에요. 처음 만든 HTML 프로토타입은 `prototype/`에 참고용으로 그대로 들어 있어요.

## 실행하기

1. [Godot 4.4 이상](https://godotengine.org/download)을 설치해요. (.NET 버전이 아닌 일반 버전)
2. Godot에서 **가져오기(Import)** → 이 폴더의 `project.godot`을 골라요.
3. **F5**(프로젝트 실행)를 누르면 타이틀 화면부터 시작해요.

프로토타입은 `prototype/index.html`을 브라우저로 열면 바로 해 볼 수 있어요.

## 지금 들어 있는 것

**코어 루프 (최소 버전)**

타이틀 → 씨앗 고르기 → 시대 선택 → 선택 결과(우주 변화 표시) → (가끔 돌발 사건) → … 12개 시대 … → 결말

- 선택하면 우주 상태 값이 바뀌고, 결과 화면에서 무엇이 얼마나 바뀌었는지 보여 줘요.
- 중간에 우주가 끝나 버리는 조건(물질 0, 너무 무거움 등)과 진공 붕괴도 프로토타입과 똑같이 동작해요.
- 학자 카드는 선택 결과 화면에 나와요.
- 화면은 아직 기능 확인용 기본 UI예요. 그림, 애니메이션, 도감, 저장은 아직 없어요.

## 폴더 구조

```
project.godot          Godot 프로젝트 설정 (세로 화면 720×1280)
scenes/main.tscn       메인 화면
scripts/
  game_data.gd         data/*.json 을 읽는 전역 저장소 (오토로드 GameData)
  universe.gd          한 판의 우주 상태와 규칙 (효과 적용, 조건 검사, 사건, 결말)
  main.gd              화면 흐름과 기본 UI
data/                  게임 내용 (아래 참고)
tests/
  simulate.tscn        2000판을 자동으로 끝까지 돌려 결말 분포를 출력
  ui_smoke.tscn        메인 화면 버튼을 자동으로 눌러 30판 진행
tools/
  extract_prototype_data.mjs   프로토타입에서 data/*.json 을 다시 뽑는 스크립트
prototype/index.html   처음 만든 HTML 프로토타입 (수정하지 않음)
```

## 게임 데이터 (`data/`)

게임 내용은 모두 JSON에 있어서, 코드를 건드리지 않고 문장이나 수치를 고칠 수 있어요.

| 파일 | 내용 |
|---|---|
| `stages.json` | 12개 시대. 설명, 용어, 선택지(44개), 각 선택지의 효과와 결과 문장 |
| `events.json` | 돌발 사건 13개. 나오는 시대, 조건, 선택지, 주사위 결과 |
| `endings.json` | 결말 14개. 판정 조건(위에서부터 검사), 결말 이야기, "미지의 우주" 차이점 문구 |
| `gauges.json` | 화면에 보이는 게이지 6개와 "우리 우주" 범위 |
| `seeds.json` | 시작 씨앗 4가지 |
| `sages.json` | 학자 카드 24장 |
| `rules.json` | 시작 값, 값 범위, 사건 확률, 진공 붕괴, 중간 종료 조건 |

### 우주 상태 값

| 키 | 뜻 | 기준 |
|---|---|---|
| `D` | 물질 밀도 | 50 = 임계밀도 |
| `F` | 밀도 요동 | 50 = 10만분의 1 |
| `M` | 물질이 살아남은 정도 | 0이면 물질 없음 |
| `C` | 헬륨 비율 | 50 = 헬륨 25% |
| `DM` | 암흑물질 | 50 = 보통 물질의 5배 |
| `L` | 암흑에너지(미는 힘) | 30 = 없음, 60 = 우리 우주, 90 이상 = 빅 립 |
| `LIFE` | 무거운 원소 | 0 기준, 화면에는 +50 해서 표시 |
| `age` | 우주 나이 | 10억 년 단위 |

### 선택지 효과 (`effects`)

| op | 뜻 | 예 |
|---|---|---|
| `add` | 더하기 | `{"op":"add","key":"F","value":18}` |
| `add_random` | 범위 안에서 무작위로 더하기 | `{"op":"add_random","key":"D","min":-14,"max":14}` |
| `set` | 값 정하기 | `{"op":"set","key":"M","value":0}` |
| `scale_from` | 기준에서 벗어난 만큼을 늘리거나 줄이기 | `{"op":"scale_from","key":"D","center":50,"factor":0.2}` |
| `move_toward` | 목표 쪽으로 일정 비율 이동 | `{"op":"move_toward","key":"F","target":50,"amount":0.6}` |
| `flag` | 특수 표시 켜기 | `{"op":"flag","flag":"vac"}` |

주사위 선택지는 `effects` 대신 `dice` 목록을 가지고, 각 항목에 `chance`(확률), `effects`, `result`가 있어요.

### 조건식

결말, 사건, 중간 종료, 설명 바뀜에 같은 형식을 써요.

```json
{"key": "D", "op": ">=", "value": 88}
{"flag": "noinf"}
{"not_sage": "penzias"}
{"all": [ ... ]}   모두 만족
{"any": [ ... ]}   하나라도 만족
```

## 테스트

Godot 에디터에서 `tests/simulate.tscn`을 열고 **F6**을 누르거나, 명령줄에서:

```
godot --headless --path . res://tests/simulate.tscn
godot --headless --path . res://tests/ui_smoke.tscn
```

`simulate`는 무작위로 2000판을 돌려 결말별 횟수를 출력해요. 데이터를 고친 뒤 특정 결말이 안 나오게 되었는지 확인할 때 써요.
